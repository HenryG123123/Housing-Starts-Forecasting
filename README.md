# Housing Starts Forecasting

## Project Background

This project analyzes monthly U.S. housing starts using R Studio. Housing starts measure new residential construction activity and serve as an important indicator of the U.S. housing market and economy. The goal is to identify seasonal patterns, understand long-term trends, and forecast future housing starts.

## Data Dictionary

| Variable | Description |
|---|---|
| HOUSTNSA | U.S. Housing Starts, Not Seasonally Adjusted |
| Source | Federal Reserve Economic Data (FRED), U.S. Census Bureau |
| Frequency | Monthly |
| Time Period | January 1959 – August 2026 |
| Unit | Thousands of housing units, at an annual rate |
| Missing Values | None |
